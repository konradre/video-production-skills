# The risk register — written before the first generation, with each mitigation already in the shot list

| risk | where it bites | the mitigation that is already in the plan |
|---|---|---|
| **content filters** (the big one) | the explicit frame, the product's pieces, the premise once a rewriter restates it | the pieces are a post layer; the explicit frame is never framed (reactions); the explicit line is post audio; a refused scene is re-staged as a silhouette or a tighter reaction crop — never a rewrite of the joke; a refused spoken line is dubbed (`spot-audio-assembly`) |
| **moderation on a word** | a line the venue refuses in-gen | the take says a similar-mouth word; the client's line is dubbed in the character's clone |
| **lipsync** | every on-camera line | decide per line before generating: reaction-led framing (hold on the listener), a wide/over-shoulder where the mouth is not the focus, or the venue that renders dialogue verbatim; the line-deliverer faces the camera |
| **transformation geometry** | every before/after pair | the B plate generated FROM the A keeper's frame 0; the start image = the previous shot's last state |
| **text in frame** | banners, garments, name dings, the card | always composited (`designed-elements`) |
| **packaging fidelity** | any hero shot of the pack | designed turntable/display; or the shot held near-static with the pack composited |
| **likeness** | a generated cast member who resembles a public figure | re-roll the cast ref; a real person's voice as a clone is stated once |
| **platform copy risk** | the vulgar lines | flagged ONCE with the fallback register; the client rules; risqué first, fallbacks parked; a rejection deploys the fallback for that asset only |
| **fill continuity** | every shot with pieces | one particle source per SKU; every shot names its `ELEM-FILL-*`; audited on any SKU move |
| **venue cost at the campaign's shot count** | the whole build | the cost per keeper (not per second) with realistic attempt counts; the Phase-0 test before any scale |
| **the easiest spot proving the chain** | the first spot | know what it proves; pair it with a reference test and a lipsync test |

## The fallback register (built with the originals, parked, never pre-emptively deployed)

| ships as | parked fallback | cost of the fallback |
|---|---|---|
| the risqué line | the toned-down line | an audio swap (trivial; can wait for a rejection) |
| the text gag on a garment | the innocent variant on the same garment | a second generated/designed card — build it in the SAME batch as the original |
| the product-vocabulary lines | none needed | naming the product is unavoidable; it is what the product is |

## Open decisions

Kept as a numbered list with the owner (client / operator / tooling) and the trigger that closes each;
closed items stay in the list, struck through, with the date and who closed them.
